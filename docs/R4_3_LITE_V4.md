# R4.3：Lite V4 后端更新

本版更新 GPU Block，CPU DIS、GPU DIS、AMD 光流和 Intel 视频接口的算法不变。GPU DIS 与 AMD 光流继续是实验项。Arc A 系列兼容模式、三种处理模式、编码器与特效选择保持可用。

## 改了什么

Lite V4 在半宽半高网格做半径 8 的正反向搜索，恢复全分辨率后做 refine；不是简单地将 Full H2 改名。此次修复置信度重评估的共享内存越界（扩大至合法 halo10），再消除不必要的搜索寻址与 clamp。修复保持获胜光流不变，置信度与独立合法纹理参考一致；置信度修正可以影响最终画面。

交付 shader SHA256：`344f2dc0731178026491cf55fb9dfae4981d63218b428164582f38cefe6e596a`。

严格等价优化的对照是合法 halo10，不是旧的越界读取版本。用户已看过完整样片后批准发布，不用 PSNR 代替视觉结论。

## 本轮证据与边界

- B580 独立 motion：1080×1920 输入 3.478→2.630 ms/帧对；2160×3840 输入 13.770→10.475 ms/帧对。仅算法阶段，不含解码、深度、XeSS、编码，不保证整片同幅度加速。
- 完整 300 帧赛车 SR、621 帧人像 SR→FG 的合法 halo10 与优化版输出逐位一致；全片可解码，帧数、音轨、PTS 通过。
- 发布候选的三个真实节点方法各用 8 帧带音轨输入验证：SR 输出 8 帧，FG/组合各 15 帧；实际调用原生引擎与运行库。只有 ComfyUI 的 VideoFromFile 返回包装用替身，未冒充完整浏览器队列测试。
- 运行库按最终 ZIP 安装和逐文件哈希再验收。未改用户 ComfyUI/Python，不要求另装 PyTorch。
- 本轮是 Windows 11 / Intel Arc B580；没有新的跨显卡或长时间稳定性结论。

## 更新

已有 R4 节点执行 `git pull --ff-only`，重启 ComfyUI 并刷新页面；自动获取 R4.3 对应的运行库。网络不便时下载该 Release 的 Runtime ZIP，用 `install_runtime.bat -AssetPath` 指定。不要将 ZIP 直接覆盖到 ComfyUI 根目录。

R3 节点仍需替换为 R4 节点，历史分叉的安装按 README 备份后重新克隆；不要强制重置本地修改。
